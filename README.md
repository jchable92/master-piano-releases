# Master Piano · builds

Aquí solo van las versiones compiladas de **Master Piano**, una app para aprender piano con un
teclado MIDI por USB-C (Android, en horizontal). El código fuente vive en un repositorio privado.

## Descargar

Cada versión está en [Releases](../../releases). Elige el APK según tu teléfono:

| Archivo | Para |
|---|---|
| `…-arm64-v8a-release.apk` | Casi todos los teléfonos actuales (recomendado) |
| `…-armeabi-v7a-release.apk` | Teléfonos de 32 bits, más antiguos |
| `…-x86_64-release.apk` | Emuladores y Chromebooks |

`SHA256SUMS.txt` trae la huella de cada archivo para comprobar la descarga.

## Instalar

1. Descarga el APK en el teléfono.
2. Ábrelo y permite instalar apps de esa fuente cuando Android lo pida.
3. La primera vez la app descarga el sonido de piano (unos 35 MB).

Las builds están firmadas con una clave de desarrollo: sirven para instalar a mano, no para Google
Play. Si tenías una versión con un número mayor, desinstálala antes.
